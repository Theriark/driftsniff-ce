{# The metric card (section 3 of the UI standard, THE-359 P1): a label, one big number with an optional unit, a sparkline of the series and one line that says what changed. The whole card is the link to the filtered view behind the number. tone colours the line: down (good), up (worth a look), alert (needs a decision); none is neutral. trend is the direction of the count against the previous period: up, down or flat. The colour never works alone: a glyph and the words carry the same meaning. With a trend the glyph is the arrow (or the dash for flat); without one an up tone shows the high shape and an alert tone the critical shape, the same shapes as the severity badges. A screen reader hears one sentence, the visually hidden span; the visible parts are hidden from it so the label, the number and the line are not read twice. The sentence starts with the label, so the visible name is part of the spoken name. A series that is all zeros draws no sparkline: a flat line at the bottom says nothing a zero does not. #} {% macro metric_card(label, value, href, unit="", delta="", tone="", trend="", spark=[]) %} {%- set trend_glyphs = {"up": "i-trend-up", "down": "i-trend-down", "flat": "i-dash"} -%} {%- set tone_glyphs = {"up": "sev-high", "alert": "sev-critical"} -%} {%- set glyph = trend_glyphs.get(trend) or tone_glyphs.get(tone) -%} {%- set drawn = spark | select | list | length > 0 -%} {{ label }}: {{ value }}{% if unit %} {{ unit }}{% endif %}.{% if delta %} {{ sentence(delta) }}{% endif %}{% if drawn %} Last {{ spark | length }} values: {{ spark | join(", ") }}.{% endif %} {{ label }} {{ value }}{% if unit %} {{ unit }}{% endif %} {% if drawn %} {% endif %} {% if delta %} {% if glyph %}{% endif %}{{ delta }} {% endif %} {%- endmacro %}
