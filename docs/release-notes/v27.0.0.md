## What it is

driftsniff CE is a self-hosted tool that records changes to the configuration of your network,
virtualisation, storage, home automation and monitoring systems. It keeps the before and after
values of every change and gives each change an explainable risk label. It runs as one container
with two volumes and needs no separate database server.

- **Collection.** Fourteen kinds of system read on a schedule (1 to 60 minutes) with read-only
  credentials where the system offers them: UniFi Network, UniFi Protect, Xen Orchestra, Proxmox
  VE, Portainer, TrueNAS, Synology DSM, QNAP QTS / QuTS hero, Redfish BMCs (iDRAC, iLO,
  Supermicro), Home Assistant, Grafana, Prometheus, Zabbix and Checkmk. Four TLS modes and a
  read-only Test connection for each. Push sources take a configuration from a sender with a
  per-source key.
- **Change detection.** Each reading is redacted, normalised and compared with the one before.
  Only differences are stored. Secrets are kept as keyed fingerprints. Each item is rated low,
  medium, high or critical by a named rule with its reason.
- **Web interface.** Dashboard with stat cards, open changes by severity, Needs attention, drift
  lines, a 3D view of your lab, a 30 day trend, breakdowns and an activity timeline; the change
  list with filters, sort and mutes; the change detail with before and after, rules,
  acknowledgements, notes and external analysis; sources with filters, change replay and
  coverage; history and configuration; settings; an Account page for display name, picture,
  password and theme. Light and dark themes, layouts from 390 to 1440 px, keyboard operation.
- **Access.** Viewer, operator and admin roles; first-admin setup with a one-time code; sign-in
  limits and locks; API tokens with read and enrich scopes.
- **Integrations.** `/api/v1` to read changes and attach external analysis; one notification
  channel (signed webhook or SMTP).
- **Operations.** Health route, online backup with an integrity check, nightly retention (30 to
  365 days), master key rotation, hardened container, audit events for every admin action.

## Changed since v27.0.0-rc.5

- **Twelve more kinds of system.** Portainer, TrueNAS, Synology DSM and QNAP; then Proxmox VE,
  Home Assistant, Redfish, Grafana, Prometheus, Zabbix, Checkmk and UniFi Protect. Each has a
  setup guide in [guides](../guides) and a rule pack.
- **Checked on real systems.** UniFi Network, Xen Orchestra, TrueNAS, Portainer, Checkmk, Home
  Assistant and Grafana were read on lab systems, and the collectors, type tables and rules were
  corrected to what those systems really return (see
  [Checked on real systems](#checked-on-real-systems)).
- **No false changes.** A value that only moved between clear text and a fingerprint is no
  longer reported; an object whose key moved between the two is matched as one object. Xen
  Orchestra's hourly heartbeat in the pool's `otherConfig` is dropped (normaliser version 3).
- **Ratings.** A Xen Orchestra description change and a Grafana folder rename are rated low.
- **Web interface.** The Inter typeface ships with the application, pages cross-fade, the
  dashboard shows a 3D lab of your sources as devices with status lights, and a source page
  replays its changes on its device. The header no longer shows an environment badge. New Account
  page.
- **Fixes from the release review.**
  - The severity ring and the dashboard breakdowns count changes, the same unit as the list each
    row opens; the ring's centre says "open changes".
  - A resource label that two products share names its product, on the dashboard and in the
    Changes resource filter ("Checkmk hosts", "Zabbix hosts").
  - The Redfish vendor is named once, and the dashboard product line stops at two lines with the
    whole text in its title.
  - The Sources list filters by kind and status and sorts by its column headings; sorting by
    version compares the numbers (2.21.4 before 12.2.1). A disabled source says Disabled instead
    of No check yet.
  - Every reading in History opens the configuration it stored, and its Changes found opens only
    that reading's changes. A single change is announced as "1 change found by this reading".
  - Source names in the breakdowns wrap to two lines; Escape closes the user menu and the phone
    menu.
  - The picture upload on the Account page works in every browser, and a refused upload removes
    the earlier "saved" message.
  - A change's number has no thousands separator ("Change 2079").
  - The application reports its version, 27.0.0, instead of the package placeholder.
- **Master key rotation completes.** The rekey is finished by one clean collection cycle: while
  it runs, `serve` loads the old key, stored fingerprints of unchanged secrets are re-stamped
  without a change, a real secret change is still reported, and the `fingerprint_rekey` event
  ends the rekey so a later one can start. See [key-management.md](../key-management.md).
- **Development-only start-up data** is switched on by the setting `DRIFTSNIFF_DEV_HOST_SUFFIX`
  (unset by default) instead of a built-in host name. See
  [configuration.md](../configuration.md#development-only-settings).
- **Container.** The image picks up the Debian security updates of OpenSSL and Linux-PAM.

## Checked on real systems

Seven integrations were checked on lab systems run by the maintainers on 13 and 14 November 2026,
with read-only intent. For each one: the account the setup guide asks for, every resource read,
every stored field classified, a second run with no change reported, and one harmless setting
changed and reverted with both changes reported.

| System | Version | Account | Resources | Change test |
|---|---|---|---|---|
| UniFi Network (two consoles) | 10.6.109 | API key of an owner account | 14 of 14 | firewall policy description set and cleared: low |
| TrueNAS Community Edition | 25.04.2.6 | user with only the Read-Only Administrator privilege | 18 of 18 | SMB share description set and cleared: high |
| Portainer Business Edition | 2.45.3 | access token of an administrator | 10 of 10 | a stack file changed by an image update: high |
| Checkmk Community | 2.5.0p14 | automation user, a copy of `admin` without "Make changes, perform actions" | 9 of 9 | contact group alias set and restored: medium |
| Home Assistant | 2026.10.4 and 2026.11.1 | long-lived token of an administrator | 8 of 8 | entity name override set and cleared: low |
| Grafana | 13.3.0 | service account with the Admin role | 10 of 10 | folder renamed and renamed back: low |
| Xen Orchestra (two servers, one pool) | XO 5 (2026 build) | authentication token of an administrator | 20 of 20 | pool description set and cleared: low |

Synology DSM, QNAP, Proxmox VE, Redfish, Prometheus, Zabbix and UniFi Protect are tested against
simulations and the fakes in `tests/contract` only. Their setup guides mark the statements about
the vendor side that no real system has confirmed.

## Known limits

- The seven integrations above were not checked with every option: a UniFi View Only account, a
  Xen Orchestra user with a read-only ACL role, TrueNAS NFS, iSCSI, replication, cloud sync and
  cron jobs, Portainer Edge groups, teams and tags, and Checkmk host and service groups.
- A CA bundle is not uploaded in the browser: put the PEM file in `/data/ca` and type its file
  name in the source form.
- A credential's expiry warning comes from the date an admin enters in the source form; the
  expiry Xen Orchestra reports itself is not read.
- A user's role cannot be changed and another user's password cannot be reset from the
  interface; a locked user is unlocked by itself after 15 minutes. Each user changes their own
  password on the Account page.
- No bulk acknowledge and no CSV export of changes.
- A nightly retention run that is missed while the application is stopped is not made up.
- One notification channel per installation.

## Upgrade from a release candidate

Take a backup, run the `27.0.0` image with `docker compose up -d` and check `/healthz`; see
[operations.md](../operations.md). The database is migrated at start. If you set
`DRIFTSNIFF_ENVIRONMENT_LABEL` for a candidate, remove it: it is no longer read.
